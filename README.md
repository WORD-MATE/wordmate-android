# wordmate-android

매일 10분, 단어로 겨루고 성장하는 영단어 학습 앱 **WORD MATE**의 학생용 앱입니다.
Figma `WORD MATE` 파일의 **App-학생** 페이지와 **Design System** 페이지를 기준으로 Flutter로 구현했습니다.

## 기술 스택

| 구분 | 사용 |
| --- | --- |
| 프레임워크 | Flutter 3.47 / Dart 3.13 |
| 상태 관리 | `ChangeNotifier` 기반 `AppStore` + `ListenableBuilder` (외부 패키지 없음) |
| 화면 이동 | `Navigator` + `MaterialPageRoute`, 하단 탭은 `IndexedStack` |
| 플랫폼 기능 | 단어 발음: `MethodChannel` → Android `TextToSpeech` (`MainActivity.kt`) |
| 대상 | Android (`com.wordmate.android`) |

외부 패키지 없이 Flutter SDK만 사용합니다.

## 폴더 구조

```
lib/
├── main.dart            앱 시작, 테마, 첫 화면(로그인/메인) 결정
├── data/                모델 · 샘플 데이터 · AppStore(앱 전역 상태)
├── utils/               테마 토큰(theme.dart), 화면 이동, 숫자 포맷, TTS
├── widgets/             공통 위젯(버튼, 입력, 칩, 카드, 시트 등)
└── screens/
    ├── main_screen.dart 하단 탭 5개
    ├── auth/            로그인, 약관 동의
    ├── home/            홈, 알림 팝업
    ├── wordpack/        단어팩 목록·상세, 내 단어팩 만들기·편집, 신고
    ├── study/           학습 설정, 플래시카드/4지선다/직접 입력, 결과
    ├── battle/          대결 홈, 방 만들기, 대기실, 코드 참가, 대결 진행·결과
    ├── ranking/         랭킹
    └── mypage/          마이페이지, 배지, 설정, 공지, 고객센터
test/                    스토어·학습·대결 로직 단위 테스트
```

## 구현 화면

- **인증**: DataGSM 로그인, 약관 전체/개별 동의, 약관 상세
- **홈**: 히어로 카드, 연속 학습·레벨·오늘 XP, 오늘 할 일, 이어서 학습, 오늘의 문장, 일일 미션(XP 받기), 랭킹 미리보기, 알림 팝업
- **단어팩**: 기본/내 단어팩, 검색·카테고리 필터, 상세(학습 상태 필터, 뜻 가리기, 발음 듣기, 즐겨찾기), 신고, 내 단어팩 만들기·단어 추가/수정/삭제·팩 삭제
- **학습**: 학습 방식·출제 옵션 설정, 플래시카드, 4지선다, 직접 입력, 중단 확인, 결과(틀린 단어만 다시 풀기)
- **대결**: 빠른 대결 매칭, 대결방 만들기(단어팩 고르기, 점수 방식·문항 수·시간·인원), 대기실(코드 복사), 코드로 참가, 타이머·점수·이모지 반응이 있는 대결 진행, 결과(시상대·순위·신고), 틀린 단어, 대결 기록
- **랭킹**: 범위(학교/학년/반/친구)·기간(주간/월간/전체) 필터, 시상대, 내 순위 고정
- **마이**: 프로필·레벨·통계, 랭킹 배지, 설정(알림, 로그인 관리, 로그아웃·탈퇴), 공지사항, 고객센터 문의

## 실행

```bash
flutter pub get
flutter run                 # 연결된 기기/에뮬레이터에서 실행
flutter test                # 단위 테스트
flutter build apk --release # APK 빌드
```

## 참고 사항

- **서버 연동 전 상태**: 모든 데이터는 `lib/data/sample_data.dart`의 샘플이며 앱을 재시작하면 초기화됩니다. API가 준비되면 `AppStore`의 메서드 시그니처를 유지한 채 내부만 API 호출로 바꾸면 됩니다.
- **로그인**: DataGSM OAuth는 아직 연결하지 않았고, 버튼을 누르면 바로 로그인된 상태가 됩니다.
- **대결**: 실시간 서버가 없어 상대 입장·점수는 기기 안에서 시뮬레이션합니다.
- **공유**: 공유 패키지를 쓰지 않아 초대 코드·결과 공유는 클립보드 복사로 동작합니다.
- **폰트**: 시안 폰트 파일은 포함하지 않아 시스템 기본 폰트를 사용합니다. 폰트를 추가하고 `utils/theme.dart`의 `AppText.fontFamily`만 바꾸면 전체에 적용됩니다.
- **범위**: Figma의 App-교사 / App-관리자 페이지는 포함하지 않았습니다.
